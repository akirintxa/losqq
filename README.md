# losqq.com

Landing de [losqq.com](https://www.losqq.com): la vitrina de las apps que voy construyendo.

Stack: Next.js (App Router, todo estático), Tailwind CSS 4, fuentes Urbanist y Stack Sans Notch. Se despliega en Vercel.

## Agregar una app

Suma una entrada a `APPS` en [`src/data/apps.ts`](src/data/apps.ts). La tarjeta del inicio y la ficha `/apps/<slug>` se generan solas.

## Desarrollo

```bash
npm install
npm run dev
```
